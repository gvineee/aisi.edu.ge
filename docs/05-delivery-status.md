Dev რეჟიმში HMR-ის დროს იყო renderer/optimizer შეტყობინებები; ცალკე build და საბოლოო HTTP პასუხი წარმატებულია. ეს არ არის production გარემოს გამძლეობის ტესტი.

## დემოს საზღვრები

ფორმა არ აგზავნის მონაცემებს. გადახდა არ სრულდება. წიგნების რეალური ფაილები არ ახლავს. ლოგო არის კონცეფციური PNG და არა დასრულებული ვექტორული იდენტობის პაკეტი. როლების გადამრთველი პრეზენტაციის საშუალებაა და არა ავტორიზაცია. მონაცემები, სტატისტიკა, შეხვედრის თარიღი და თანხები საჩვენებელია. გრაფიკი დემო კვირას აჩვენებს და რეალურ დასწრებას არ ასახავს.

საჯარო დიზაინის ტექსტები შემოთავაზებულია და სკოლამ უნდა დაამტკიცოს; საიტის არცერთი ცვლილება aisi.edu.ge-ზე არ გამოქვეყნებულა. ყველა მასალა ამ საქაღალდეში რჩება.

## სკოლასთან დასაზუსტებელი შემდეგი გადაწყვეტილებები

1. EduPage: შენარჩუნება, ოფიციალური ინტეგრაცია თუ ეტაპობრივი ჩანაცვლება; ექსპორტის/API-ის შესაძლებლობის დადასტურება.
2. ავტორიზებული სკოლის წარმომადგენელი კონტენტის, მიღების წესების, საფეხურების, გადასახადებისა და მედიის დასამტკიცებლად.
3. გადახდის პროვაიდერი და ფინანსური აღრიცხვის წესები; sandbox credentials შესაბამისი ფაზისთვის.
4. მშობლის/მეურვის კავშირების დადასტურება, შენახვის ვადები და უფლებები.
5. აისის პირველი ინსტალაციის მოდელი და შემდგომი კომერციული პლატფორმის ეტაპი.

ეს საკითხები საჯარო დიზაინის განხილვას არ აჩერებს. მათი გადაწყვეტა აუცილებელია შესაბამისი ფუნქციური მოდულის რეალურ მონაცემებზე გაშვებამდე.

## დამატება: სასკოლო სერვისები და დოკუმენტების ცენტრი

დაემატა სერვისების დემო (შეხვედრა, კლუბები, თანხმობა, გაცდენა), დირექტორის როლი და დოკუმენტების ცენტრის ინტერაქტიული სცენარი. სპეციფიკაციებია `06-platform-growth.md` და `07-document-management-spec.md`. ამ დამატებებზე `npm run build` და TypeScript `--noEmit` წარმატებით დასრულდა. ბრაუზერული click-through და რეალურ მოწყობილობაზე ვიზუალური შემოწმება ამ დამატებისთვის არ ჩატარებულა. რეალური ფაილების upload/storage/approval backend არ განხორციელებულა; shared workspace-ში არსებული Laravel ცვლილებები კლოდის დამოუკიდებელი სამუშაოა.
