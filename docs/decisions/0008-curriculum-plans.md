# 0008 — სასწავლო გეგმები და თემების გავლა

თარიღი: 2026-10-28

## გადაწყვეტილება

- **გეგმა:** ერთ კლასს ერთ საგანში ერთი წლიური გეგმა აქვს (`curriculum_plans`, unique class + subject).
- **თემები:** გეგმაში თემები თანმიმდევრობითაა (`curriculum_topics`). თითოეულს აქვს დაგეგმილი გაკვეთილების რაოდენობა და, სურვილისამებრ, თარიღები.
- **ჟურნალთან კავშირი:** ჟურნალის ჩანაწერს (`lesson_records`) ახლა `curriculum_topic_id` აქვს. მასწავლებელი გაკვეთილზე გეგმის თემას ირჩევს, სისტემა კი გაუვლელ პირველ თემას სთავაზობს. თავისუფალი ტექსტი შენიშვნად რჩება.
- **წინსვლის დათვლა** (`CurriculumProgress`):
  - **გავლილი:** თემა, რომელიც ამ კლასისა და საგნის ერთ ჟურნალის ჩანაწერში მაინც არის მითითებული.
  - **ჩამორჩენილი:** თემა, რომლის დაგეგმილი ბოლო თარიღი გავიდა, თვითონ კი ჯერ არ გავლილა.
  - გამოთვლა ცალკე არ ინახება, ყოველთვის ჟურნალიდან ხდება.
- **კლასისა და საგნის სია:** იკრიბება მასწავლებლების დატვირთვიდან, განრიგის გაკვეთილებიდან და არსებული გეგმებიდან, ასე რომ, EduPage-იდან იმპორტირებული ყველა წყვილი ჩანს.

## უფლებები (`CurriculumAccess`)

| ვინ | რა შეუძლია |
|---|---|
| ადმინი, დირექტორი, აკადემიური მენეჯერი | ყველა გეგმის ნახვა და შეცვლა, დამტკიცება, მონახაზად დაბრუნება |
| მასწავლებელი | თავისი კლასისა და საგნის გეგმის შედგენა, ოღონდ მხოლოდ სანამ მონახაზია. სხვისი გეგმის ნახვა და კოპირება (გეგმა პირადი მონაცემი არ არის) |

- **თემის მიბმა ჟურნალში:** გაკვეთილს მხოლოდ თავისი კლასისა და საგნის გეგმის თემა მიება.
- **აუდიტი:** `curriculum.plan_created`, `curriculum.topics_added`, `curriculum.topic_removed`, `curriculum.plan_approved`, `curriculum.plan_reopened`.

## ჯერ არ არის

- მოსწავლე და მშობელი გეგმას ჯერ ვერ ხედავენ.
- ეროვნული სასწავლო გეგმის შედეგებთან და კომპეტენციებთან კავშირი არ არის.
