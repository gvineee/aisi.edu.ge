# 0002 — დიზაინის წყარო ფაზა 1-ისთვის

თარიღი: 2026-09-10 · სტატუსი: მიღებული (ფაზა 0), გადასამოწმებელი მომხმარებელთან

## კონტექსტი

`CLAUDE.md` ავალდებულებს: „გადაიტანე `design/`-ის ვიზუალური ენა React კომპონენტებში" და „თუ სპეციფიკაცია და არსებული დიზაინის დემო ერთმანეთს განსხვავდება, ბიზნესწესი აიღე სპეციფიკაციიდან; ვიზუალური ენა დიზაინიდან. არსებითი წინააღმდეგობა აღწერე და გადაწყვეტილება დოკუმენტში შეიტანე."

`design/` საქაღალდის რეალური შემოწმებით (ფაზა 0):

- `design/app/page.tsx` არის ერთადერთი გვერდი და მთლიანად skeleton/loading-state UI ინგლისურად, სათაურით „Building your site" / „Your site is taking shape". ის არ შეიცავს არც ერთ რეალურ აისის გვერდის კომპოზიციას (hero, პროგრამები, მიღება, კონტაქტი და ა.შ.).
- `design/package.json` აჩვენებს, რომ ეს არის auto-generated scaffold ცალკე ხელსაწყოსგან — `vinext` (Next.js-ის ალტერნატივა), Cloudflare `wrangler`, `@openai/sites-vite-plugin`, `.openai/hosting.json` (`d1`/`r2` null placeholder-ებით). ეს stack პრინციპულად შეუთავსებელია CLAUDE.md-ის Laravel + Inertia + Vite მოთხოვნასთან და არც ცდილობს მისი თავსებადობა.
- არსად ჩანს აისის ლოგო, ბრენდის ფერები (Midnight/Dawn/Teal), ან ქართული ტიპოგრაფია. `design/`-ს არა აქვს აისისთვის სპეციფიკური ვიზუალური გადაწყვეტილება — ის ზოგადი UI ტულინგის დემოა.
- რეალურად გამოსადეგი ნაწილია მხოლოდ `design/components/ui/*` — სრული shadcn/ui + `@base-ui/react` კომპონენტების ბიბლიოთეკა (accordion, dialog, sheet, tabs, calendar, chart და სხვ.) და `design/app/globals.css`-ის token-ური სტრუქტურა (CSS custom properties + `@theme inline` Tailwind v4 პატერნით).

## გადაწყვეტილება

1. **`design/`-ს არ ვეპყრობით როგორც აისის ვიზუალურ მაკეტს.** ის არ შეიცავს ასეთს. ამ ფაქტს ვთვლით არსებით წინააღმდეგობად handoff-ის მოლოდინსა და რეალურ ფაილებს შორის — დაფიქსირებულია აქ, ინსტრუქციის თანახმად.
2. **ვიზუალური ენის წყაროდ ვიღებთ `docs/03-brand-and-marketing.md`-ს**: ფერის token-ები (Midnight #132B45, Dawn #F5683C, White #FFFFFF, Cloud #F4F7FA, Teal #147D78, Muted #526579), Noto Sans Georgian ტიპოგრაფია, closed/rounded ფორმების მიმართულება, ლოგოს კონცეფცია (გახსნილი წიგნი + ამომავალი მზე). ეს ტექსტში აღნიშნულია როგორც „შემოთავაზებული" — საბოლოო დამტკიცებამდე ვიყენებთ, როგორც სამუშაო default-ს, არა როგორც დადასტურებულ ბრენდბუქს.
3. **კომპონენტების ტულინგად ვიღებთ shadcn/ui პატერნს** `design/components/ui/*`-დან, მაგრამ ხელახლა ავაწყობთ Laravel-ის Vite + React (არა vinext/Next.js) გარემოში, Tailwind-ის იმ ვერსიით, რომელსაც Laravel-ის ოფიციალური React starter kit მოიტანს. კომპონენტების `.tsx` source გამოგვადგება საწყის წერტილად (import path, variant-ების სტრუქტურა cva-თი), არა როგორც copy-paste, არამედ როგორც არქიტექტურული მაგალითი.
4. **`design/app/page.tsx`-ის loading-skeleton კომპოზიცია არ გადაგვაქვს არსად** — ის არ წარმოადგენს არც ერთ დაგეგმილ საჯარო გვერდს (`docs/02`, თავი 4-ის მიხედვით: მთავარი, შესახებ, სწავლა, მიღება, სასკოლო ცხოვრება, სიახლეები, კალენდარი, რესურსები, კონტაქტი).
