# 0007 — სკოლის კალენდარი

თარიღი: 2026-10-28

## გადაწყვეტილება

`/portal/calendar` ყველა როლს აჩვენებს თვის კალენდარს, ოღონდ მხოლოდ იმ ჩანაწერებს, რომლებიც მისთვისაა განკუთვნილი. ვის რა გამოუჩნდება, სერვერი წყვეტს (`CalendarFeed`) აქტიური როლისა და სერვერზე შენახული კავშირების მიხედვით. client-ის მიერ გამოგზავნილ კლასის id-ს არ ენდობა.

| ვინ | რას ხედავს |
|---|---|
| პერსონალი | ყველა ღონისძიებას |
| მოსწავლე | „ყველასთვის“ და საკუთარი კლასისას |
| მშობელი | „ყველასთვის“ და იმ შვილების კლასებისას, ვისზეც აქტიური კავშირი და აკადემიური უფლება აქვს (`can_view_academic`) |

ღონისძიების სახეები: ღონისძიება, შემაჯამებელი/ტესტი, შეხვედრა, ექსკურსია, სხვა. აუდიტორია შეიძლება იყოს ყველა, მხოლოდ პერსონალი ან არჩეული კლასები (`school_event_classes`). დრო არასავალდებულოა, მის გარეშე ჩანაწერი მთელი დღისაა.

არდადეგები და დასვენების დღეები ცალკე არ ინახება. კალენდარი მათ `non_teaching_periods`-იდან აჩვენებს, მხოლოდ წასაკითხად. ამ დღეების ცვლილება ნამუშევარი საათების გვერდზე ხდება, რადგან იქ ისინი საათების დათვლაზეც მოქმედებს.

## უფლებები და აუდიტი

- **ვინ ცვლის:** ჩანაწერის დამატება, შეცვლა და წაშლა შეუძლია ადმინს, დირექტორს და აკადემიურ მენეჯერს. ეს ყოველ მოთხოვნაზე მოწმდება.
- **სასწავლო წელი:** ჩანაწერს ავტომატურად ებმება ის სასწავლო წელი, რომელშიც მისი დაწყების დღე ხვდება.
- **აუდიტი:** `calendar.event_created`, `calendar.event_updated`, `calendar.event_deleted`.
