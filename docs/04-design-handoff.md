# აისი — დიზაინის პროტოტიპი და Laravel-ზე გადატანის რუკა

მომზადებულია: 2026-09-10. ეს არის ვიზუალური და ინტერაქციის კონცეფცია. რეალური ავტორიზაცია, მონაცემთა ბაზა, წიგნების გავრცელება, გადახდა და შეტყობინებების გაგზავნა არ განხორციელებულა.

## 1. როგორ ნახოთ

დიზაინი არის `design/` საქაღალდეში. გაშვებული ლოკალური მისამართია `http://localhost:3000/`; მუშაობს მხოლოდ ამ კომპიუტერზე, სანამ პროცესია გაშვებული. ხელახლა გასაშვებად `design/`-ში გამოიყენეთ `npm run dev`. სხვა კომპიუტერზე ჯერ `npm ci`, შემდეგ `npm run dev`. მისამართი აიღეთ პროცესის გამოსავალიდან, თუ 3000 დაკავებულია.

დაიწყეთ საჯარო მთავარი გვერდით; ზედა ზოლის „პორტალის დათვალიერება“ ან „ჩემი აისი“ გადაგიყვანთ პორტალის კონცეფციაზე. დემოში ანგარიშის შექმნა საჭირო არ არის. მობილურზე პორტალს ქვედა ნავიგაცია აქვს. როლის არჩევა ხელმისაწვდომია გვერდით ზოლში ან მობილურზე ზედა ნაწილში.

## 5. მობილური ქცევა

- საჯარო გვერდი 700px-მდე ერთ სვეტად იშლება. სათაური, მოქმედება და მთავარი ვიზუალი შენარჩუნებულია.
- 950px-მდე საჯარო მენიუ იხსნება ღილაკით; პორტალის გვერდითი ზოლი ქვედა ნავიგაციით იცვლება.
- მობილურზე როლის არჩევა ზედა ნაწილშია; მასწავლებლის ჟურნალი და ადმინისტრაციის ბრენდი ცალკე მოკლე ღილაკით იხსნება.
- ბარათები: desktop-ზე 3/4 სვეტი; მობილურზე პროგრამები/წიგნები 1 სვეტი, რიცხვითი მაჩვენებლები 2 სვეტი.
- ცხრილს აქვს საკუთარი ჰორიზონტალური scroll region; გვერდმა მთლიანად არ უნდა გასრიალდეს ჰორიზონტალურად.
- ქვედა ნავიგაცია ითვალისწინებს `safe-area-inset-bottom`-ს; ქვედა კონტენტი დაფარული არ უნდა დარჩეს.
- მოდალური ფანჯარა შეზღუდულია `100dvh`-ით და შიგნით ისქროლება. დიალოგისა და არჩევის კონტროლები იყენებს ხელმისაწვდომ Base UI/Shadcn პრიმიტივებს.
- მოძრაობის შემცირების პარამეტრი პატივდება. კლავიატურის ფოკუსი ხილულია; მთავარი შინაარსისთვის არის skip link.

ეს მოთხოვნები და CSS-ქცევები განხორციელებულია; ყველა მოწყობილობაზე იდეალური მუშაობის მტკიცება არ ხდება. საბოლოო Laravel ინტეგრაციისთვის სავალდებულოა ქვემოთ ჩამოთვლილი რეალური ბრაუზერული QA.

## 6. გადასატანი კომპონენტები

`design/app/AisiConcept.tsx` არის ერთფაილიანი პრეზენტაციის ნაკადი და არა production არქიტექტურის მაგალითი. გადაიტანეთ შემდეგ ერთეულებად:

| პროტოტიპის ნაწილი | Laravel/React სამიზნე |
|---|---|
| Logo + თემის ტოკენები | `TenantBrand`, `TenantThemeProvider`, settings props |
| საჯარო header/footer | `PublicLayout` |
| Hero, ProgramCard, PortalPromo | `pages/public/Home` კომპონენტები |
| ვიზიტის მოდალი | `VisitRequestDialog` + Form Request/controller + rate limit |
| Sidebar + ქვედა ნავიგაცია | `PortalLayout` + სერვერიდან მიღებული allowed navigation |
| მშობლის დღე/ბავშვის არჩევა | `pages/parent/Dashboard`, guardian-authorized child selector |
| განრიგი | `TimetableDay`, ფაქტობრივი school calendar + timezone |
| ბიბლიოთეკა | `LibraryIndex`, debounce/server pagination, resource policy |
| გადასახადები | `InvoicesIndex`, სერვერული თანხა/სტატუსი და hosted checkout |
| დასწრების ცხრილი | `AttendanceRegister`, სერვერული validation, concurrency/version, audit |
| ბრენდის პარამეტრები | `SchoolBrandSettings`, კონტრასტის/ლოგოს/დომენის ვალიდაცია |

Vinext/Next layout, `.openai/hosting.json`, Cloudflare plugin და პროტოტიპის route wrapper Laravel-ში არ გადაიტანოთ. სამიზნეა ოფიციალური Laravel 13 + React/TypeScript + Inertia სტრუქტურა. საჯარო გვერდების SEO-სთვის შეინარჩუნეთ თავდაპირველი HTML rendering. პორტალის frontend არ უნდა შეიცავდეს მონაცემებს, რომელზეც მიმდინარე მომხმარებელს server-side უფლება არ აქვს.

პროტოტიპში ზოგი ტექსტი და მონაცემი პირდაპირ კომპონენტშია ჩაწერილი; production-ში ყველაფერი tenant-aware props, თარგმანები და domain entities-დან უნდა მოდიოდეს. როლის დამალვა UI-ში უსაფრთხოების საზღვარი არ არის. როლის გადამრთველი production bundle-ში არ მოხვდეს.
