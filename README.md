# აისი — ახალი ვებგვერდი და სასკოლო პლატფორმა

ამ საქაღალდეში თავმოყრილია კვლევა, სრული პროდუქტის პროექტი, ბრენდი/მარკეტინგი და React-ზე შექმნილი ვიზუალური პროტოტიპი. Laravel backend აქ განზრახ არ არის განხორციელებული — მის ასაწყობად განკუთვნილია Claude Code-ის ინსტრუქცია.

3. [ბრენდი და მარკეტინგი](docs/03-brand-and-marketing.md) — პოზიციონირება, კომუნიკაცია, 90-დღიანი გეგმა, კონტენტი და სავარაუდო ბიუჯეტები.
4. [დიზაინის გადაცემის ინსტრუქცია](docs/04-design-handoff.md) — ეკრანები, ქცევა, ფერები, მასალები და Laravel-ზე გადატანის რუკა.

## დიზაინის გახსნა

ლოკალური დიზაინის მისამართია **http://localhost:3000/**, სანამ სერვერი მუშაობს.

ხელახლა გასაშვებად გახსენით `design/` და გაუშვით `npm run dev`. ახალ კომპიუტერზე ჯერ საჭიროა `npm ci`. მიმდინარე პროტოტიპი იყენებს Node-სა და React-ს; PHP მხოლოდ მომავალი Laravel პროექტისთვისაა საჭირო.

ზედა ზოლიდან ან „ჩემი აისი“-დან გახსენით პორტალი. აირჩიეთ მშობლის, მოსწავლის, მასწავლებლის ან ადმინისტრაციის როლი. შეამოწმეთ განრიგი, ბიბლიოთეკა, გადახდები, ჟურნალი და ბრენდის ფერი.

## Claude Code-ისთვის საწყისი დავალება

> წაიკითხე CLAUDE.md და მასში მითითებული დოკუმენტები. შეამოწმე მიმდინარე ფაილები და უკვე შესრულებული სამუშაო. დიზაინის წყაროდ გამოიყენე design/, ხოლო ბიზნესწესების წყაროდ docs/02-product-and-platform-spec.md. დაიწყე შეთანხმებული პირველი ფაზით; შეინარჩუნე კვლევა, დიზაინი და სხვა არსებული ცვლილებები. წარმოადგინე მოქმედი, შემოწმებული შედეგი და დარჩენილი ამოცანები.

ყველა საჩვენებელი მოსწავლე, თანხა და მაჩვენებელი გამოგონილია. ფორმა მონაცემებს არ აგზავნის; გადახდა არ სრულდება. დომენზე არაფერი გამოქვეყნებულა. რეალური საიტის გაშვებამდე სკოლამ უნდა დაამტკიცოს ტექსტები, მედიის გამოყენება, მიღების წესები და EduPage-ის მიგრაციის გადაწყვეტილება.
