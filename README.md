# აისი — ახალი ვებგვერდი და სასკოლო პლატფორმა

ამ რეპოზიტორიაში არის **მოქმედი Laravel 13 + React/TypeScript + Inertia პლატფორმა** (საჯარო საიტი და სასკოლო პორტალი), მისი კვლევა, პროდუქტის სპეციფიკაცია, ბრენდის მასალა და თავდაპირველი ვიზუალური პროტოტიპი (`design/`).

- **მიმდინარე მდგომარეობა:** [docs/implementation-status.md](docs/implementation-status.md). იქ ცალკეა აღნიშნული, რა არის ლოკალურად შემოწმებული (`verified_local`), რა გამოქვეყნდა (deploy) და რა დადასტურდა მომხმარებლის გზით. deploy თავისთავად მიღებას არ ნიშნავს.
- **ბოლო მიღების აუდიტი და გასწორებები:** [docs/acceptance-audit-2026-10-31.md](docs/acceptance-audit-2026-10-31.md) · [docs/acceptance-fixes-2026-11-01.md](docs/acceptance-fixes-2026-11-01.md).
- **გაშვება ლოკალურად:** `composer install && npm ci && npm run build`, `.env` შეავსეთ `.env.example`-ის მიხედვით და შემდეგ: `php artisan migrate --seed`. ტესტები: `php artisan test`, `npm run check`, `npm run types:check`. ბრაუზერის შემოწმებები: [scripts/qa/README.md](scripts/qa/README.md).
- **Production deploy და rollback:** [docs/deployment-and-rollback.md](docs/deployment-and-rollback.md).

ქვემოთ მოცემულია თავდაპირველი handoff-ის მასალები.

## დიზაინის გახსნა

თავდაპირველი პროტოტიპის ლოკალური მისამართია **http://localhost:3000/**, როცა მისი სერვერი გაშვებულია.

ხელახლა გასაშვებად გახსენით `design/` და გაუშვით `npm run dev`. ახალ კომპიუტერზე ჯერ საჭიროა `npm ci`. პროტოტიპი მხოლოდ Node-სა და React-ს იყენებს; მოქმედ პლატფორმას PHP 8.4 სჭირდება.

ზედა ზოლიდან ან „ჩემი აისი“-დან გახსენით პორტალი. აირჩიეთ მშობლის, მოსწავლის, მასწავლებლის ან ადმინისტრაციის როლი. შეამოწმეთ განრიგი, ბიბლიოთეკა, გადახდები, ჟურნალი და ბრენდის ფერი.

## Claude Code-ისთვის საწყისი დავალება (ისტორიული)

> წაიკითხე CLAUDE.md და მასში მითითებული დოკუმენტები. შეამოწმე მიმდინარე ფაილები და უკვე შესრულებული სამუშაო. დიზაინის წყაროდ გამოიყენე design/, ხოლო ბიზნესწესების წყაროდ docs/02-product-and-platform-spec.md. დაიწყე შეთანხმებული პირველი ფაზით; შეინარჩუნე კვლევა, დიზაინი და სხვა არსებული ცვლილებები. წარმოადგინე მოქმედი, შემოწმებული შედეგი და დარჩენილი ამოცანები.

**პროტოტიპში** (`design/`) ყველა საჩვენებელი მოსწავლე, თანხა და მაჩვენებელი გამოგონილია: ფორმა მონაცემებს არ აგზავნის, გადახდა არ სრულდება. ეს არ ეხება მოქმედ პლატფორმას, რომელიც aisi.edu.ge-ზეა გამოქვეყნებული. რეალური საიტის გაშვებამდე სკოლამ უნდა დაამტკიცოს ტექსტები, მედიის გამოყენება, მიღების წესები და EduPage-ის მიგრაციის გადაწყვეტილება.
